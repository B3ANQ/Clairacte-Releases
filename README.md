# Clairacte desktop releases

Public Windows x64 and macOS Apple Silicon installers and authenticated update metadata. The development source repository remains private. No practice records, recordings, documents or credentials belong in this repository.

Use the newest published release. Transcription runs locally with bundled whisper.cpp and models, without API fees. Existing versions before the updater-enabled release need one manual upgrade.

Publisher signing and Apple notarization status are stated per release. A checksum or update signature verifies integrity; it is not an Apple/Microsoft publisher certificate or a security certification. Never disable Gatekeeper or SmartScreen globally.
